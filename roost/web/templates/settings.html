How to create a Telegram bot (step-by-step)

1. Open Telegram and search for @BotFather

2. Send /newbot and follow the prompts:

  • Choose a display name (e.g. "My Roost Assistant")
  • Choose a username ending in "bot" (e.g. "myroost_bot")

3. BotFather will give you a token like 123456789:ABCdef...

4. Paste that token in the field above and click Save

5. After saving, link your Telegram account below so the bot knows who you are

Optional: send /setdescription and /setabouttext to BotFather to customize your bot's profile.

Discord Bot checking...
Setup instructions

1. Go to discord.com/developers/applications

2. Create New Application, then go to Bot tab

3. Click "Reset Token" and copy it here

4. Enable "Message Content Intent" under Privileged Gateway Intents

5. Invite bot to your server via OAuth2 > URL Generator (scopes: bot; permissions: Send Messages, Read Messages)

6. Rebuild Docker with ENABLE_DISCORD=true

Slack Bot checking...
Setup instructions

1. Go to api.slack.com/apps and create a new app

2. Enable Socket Mode and generate an App Token (xapp-...)

3. Under OAuth & Permissions, add scopes: chat:write, app_mentions:read, im:history

4. Install to workspace and copy the Bot Token (xoxb-...)

5. Under Event Subscriptions, subscribe to: app_mention, message.im

6. Rebuild Docker with ENABLE_SLACK=true

Signal Bot checking...
Setup instructions

1. Run signal-cli-rest-api as a Docker container alongside Roost

2. Register a phone number with Signal via the API

3. Enter the API URL and phone number above

4. No Docker rebuild needed (uses httpx, already included)

Matrix Bot checking...
Setup instructions

1. Create a bot account on your Matrix homeserver

2. Generate an access token (e.g. via Element > Settings > Help > Access Token)

3. Enter homeserver URL, user ID, and token above

4. Rebuild Docker with ENABLE_MATRIX=true
